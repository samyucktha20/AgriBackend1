# AgriBackend1
Krishimitra is an agent, AI-powered voice + chat assistant designed for India’s small-scale farmers. Built using Vertex AI Agent Builder, Gemini Models, and Firebase Studio, it provides localized, intelligent agricultural support through both natural conversation and multimodal inputs.

It empowers farmers to:
📷 Diagnose crop diseases instantly by uploading images
📈 Receive market price insights and “sell/wait” guidance based on live data
🏛️ Understand and apply for government schemes via easy-to-follow explanations
🐘 Get wildlife threat alerts using GPS and real-time crowd/community info
💬 Chat or speak in their own language to get answers - no literacy or English needed
Whether the farmer prefers to talk or type, Krishimitra works in their context, their voice, and their workflow.
